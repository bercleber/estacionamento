# Diretrizes obrigatórias

1. Executar uma etapa por vez, somente quando solicitada pelo usuário. Não avançar automaticamente para a próxima etapa.
2. Ater-se apenas ao pedido do usuário, sem ampliar o escopo ou alterar decisões já acordadas por iniciativa própria.
3. Não gerar explicações, mídias, gráficos ou assuntos não solicitados.
4. Qualquer alteração no banco de dados `estacionamento`, incluindo estrutura e dados, exige ordem ou autorização explícita do usuário. O fornecimento de credenciais de acesso não autoriza alterações.
5. O backend pertence a pasta `backend` e o frontend a pasta `frontend`.
6. Aplicar boas práticas adequadas a um projeto pequeno e de estudo, sem overengineering ou complexidade desnecessária.
7. Não escrever novos testes, conforme orientação do usuário.
